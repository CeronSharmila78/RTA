Micro-Batching & Data Lake Processing

While continuous stream processing treats every tuple independently, Apache Spark Streaming discretizes continuous streams into small micro-batches of resilient distributed datasets (RDDs). In combination with Azure Data Lake Storage (ADLS Gen2), this powers high-throughput batch and stateful analytics.

flag Aim of the Experiment

To execute PySpark micro-batch transformations using Discretized Streams (DStreams), maintain stateful session totals via updateStateByKey, and inspect parquet dataset storage in the ADLS Gen2 Hierarchical Namespace.

stream DStreams & RDD Mechanics

A DStream is a continuous sequence of RDDs generated at discrete time intervals (e.g. every 2 seconds). Transformations applied to a DStream translate into transformations on each underlying RDD across Spark worker nodes.
