Module 3 · Deep Learning Acceleration

NVIDIA TensorRT Inference Engine

Standard deep learning frameworks (PyTorch, TensorFlow) prioritize flexible model training on servers. For edge inference on the Jetson Nano, NVIDIA TensorRT converts deep neural networks into optimized runtime engines by performing layer fusion, kernel auto-tuning, and FP16/INT8 reduced precision calibration.

flag Aim of the Experiment

To deploy a real-time object detection model (YOLO / MobileNet-SSD) on the Jetson Nano, configure TensorRT GPU execution with FP16 precision, capture camera frames via GStreamer, and benchmark inference latency and frame rate against CPU-only baselines.

speed Precision Modes: FP32 vs. FP16 vs. INT8

Runtime Mode Hardware Used Latency (ms) Throughput Memory Footprint
PyTorch (CPU Only) ARM Cortex-A57 (4 cores) ~215 ms 4.6 FPS ~980 MB
TensorRT FP32 128-core Maxwell GPU ~38 ms 26.3 FPS ~520 MB
TensorRT FP16 (Optimal) Maxwell GPU (Half Precision) ~16 ms 62.5 FPS ~290 MB
