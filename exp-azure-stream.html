Azure Stream Analytics (ASA) Engine

Azure Stream Analytics is an enterprise managed Complex Event Processing (CEP) engine. It uses a declarative, SQL-based syntax extended with temporal windowing primitives to analyze unbounded streams in motion with sub-second latencies.

flag Aim of the Experiment

To author and evaluate real-time Stream Analytics queries over live Event Hubs streams, configure and contrast the behavior of Tumbling, Hopping, and Sliding windows, and filter critical IoT anomaly events.

schedule Three Core ASA Windowing Primitives

1. Tumbling Window: Non-overlapping, contiguous time segments. Every event belongs to exactly one window.
GROUP BY TumblingWindow(second, 10)
2. Hopping Window: Overlapping windows that advance forward by a fixed hop interval (e.g. 10s window every 5s hop).
GROUP BY HoppingWindow(second, 10, 5)
3. Sliding Window: Only produces an output when an event enters or exits the window duration.
GROUP BY SlidingWindow(second, 10) HAVING COUNT(*) > 3
