NVIDIA Jetson Nano Architecture & Configuration

The NVIDIA Jetson Nano Developer Kit brings accelerated modern AI compute to the IoT edge. Powered by a 128-core NVIDIA Maxwell GPU and a Quad-core ARM Cortex-A57 CPU, it runs full Linux (Ubuntu 18.04/20.04 Tegra L4T) supporting CUDA, cuDNN, and TensorRT.

flag Aim of the Experiment

To assemble and configure the NVIDIA Jetson Nano edge computing system: install the MicroSD card loaded with NVIDIA JetPack, configure power jumper J48 (5V/4A DC Barrel Jack 10W mode vs. Micro-USB 5W mode), attach a MIPI-CSI camera, boot Linux, and verify system performance with tegrastats and nvpmodel.

power Power Modes & Jumper J48 Configuration

The Jetson Nano supports two power inputs and two software operational modes:

  • Micro-USB (5V / 2A = 10W max total, default 5W mode): J48 jumper pin open. Limits CPU/GPU clock frequencies to avoid voltage drops.
  • DC Barrel Jack (5V / 4A = 20W max, 10W MAXN mode): J48 jumper pin closed. Unlocks full 128 CUDA cores and 1.43 GHz CPU frequency for deep learning computer vision workloads.
