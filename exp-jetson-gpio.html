Jetson Nano 40-Pin Expansion Header

The Jetson Nano includes a 40-pin GPIO (General Purpose Input/Output) header compatible with Raspberry Pi hat standards. The official Jetson.GPIO Python library provides hardware-level digital I/O, software and hardware PWM, and edge-triggered interrupt callbacks.

flag Aim of the Experiment

To interface an output actuator (LED with current-limiting resistor) to physical Pin 18 (GPIO 24) and an input sensor (tactile push-button with internal pull-up resistor) to physical Pin 12 (GPIO 18) of the Jetson Nano, and program event-driven asynchronous control in Python.

# Jetson Nano Edge GPIO Controller
import Jetson.GPIO as GPIO
import time

LED_PIN = 18 # Output
BTN_PIN = 12 # Input

GPIO.setmode(GPIO.BOARD)
GPIO.setup(LED_PIN, GPIO.OUT, initial=GPIO.LOW)
GPIO.setup(BTN_PIN, GPIO.IN, pull_up_down=GPIO.PUD_UP)

print("[INTERRUPT] Button Pressed on Pin 12!")
